# Источники для изучения

Источники и точные commits — manifest.json. Здесь только используемые на первом этапе Quake III, Brainworks, WinQLX32, WolfcamQL, Uber Demo Tools. QuakeLiveInterface не получен при повторной попытке; игровая реализация его README не проверена.

Сохранены исходные лицензии. Свой C++ код не включает исходники этих проектов. WinQLX32 содержит GPL-3.0-or-later уведомления, Quake III — GPL-2.0-or-later; условия других проектов проверять в их собственных уведомлениях перед заимствованием. Наличие LICENSE в папке не гарантирует одинаковые условия для всех сторонних компонентов.

Изучены границы usercmd Q3, player_state и Python API WinQLX32, поток снимков UDT, серверная обработка команды WolfcamQL. Полный построчный разбор всех сторонних проектов не выполнен. Результаты и неподтверждённые возможности — ../docs/CONTROL_AUDIT.md.

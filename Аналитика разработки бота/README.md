# Аналитика разработки бота

Открыть `index.html` двойным щелчком. Работает локально через `file://`, без npm, интернета и сервера. Данные подключены через data.js, поэтому нет ограниченного браузером fetch локальных JSON. Панель не отправляет данные и не управляет игровым сервером.

Окончательный выбор владельца: **Tabler Dark** с неоновыми акцентами. Локальная CSS-копия Tabler 1.6.1 и MIT-лицензия находятся в vendor, источник и SHA-256 — vendor/manifest.json. Сторонние графические библиотеки и платные шаблоны не включены; графики построены собственным HTML/CSS.

Обновление из корня проекта:

```
python tools/update_logic_v7.py
python tools/generate_mindmap_v7.py
python tools/build_analytics.py
```

Панель показывает источник и границы каждого статуса. LIVE — историческое наблюдение из документации; для конкретной новой версии требуется отдельный журнал игрового прогона. 262 правила не означают 252 реализованных функции.

Разделы: 15 веток правил с поиском и фильтром статуса, матрица модулей, корпус игроков, разгон после остановки, LG-метрики, режимы макроигры, проверки и очередь следующих испытаний. Полный комплект PNG/SVG/OPML — в docs/mindmap_v7.

Тактический раздел: 500 повторно разобранных демок, комбо-кандидаты, движение, прицел и цепочки ресурсов. Новые combo/arrival политики LOCAL, 118 Python и 17 CTest Debug. Полный отчёт: docs/TACTICAL_RESEARCH_077_RU.md. Плакат: docs/mindmap_v7/tactical_research_077.png (6000×8001).

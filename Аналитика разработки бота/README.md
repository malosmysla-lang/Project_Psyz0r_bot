# Pracc Room Server BOT — аналитика 0.7.9

Tabler Dark / бирюзовый + фиолетовый. Открыть index.html локально или использовать опубликованный сайт. Данные — реальные записи с указанными источниками; неизвестные значения не заменяются нулями.

- 700 разобранных оригиналов из 1167; победитель и лидер урона отдельно.
- 284 правила / 15 веток, интерактивная карта с переносом узлов, масштабом и поиском.
- Текущий этап и три предыдущих, графики и гистограммы.
- Таблица дуэлей: 7 Psyz0r и 59 архивных Xaero, оружие/ресурсы/счёт, фильтры и диаграммы.
- Реестр новых матчей читает опубликованный JSON; офлайн остаётся встроенный снимок. Автообучение модели не подключено.

Для пересылки: Поделиться/Pracc_Room_Server_BOT.html. ZIP: ../out/share/Pracc_Room_Server_BOT_0_7_9.zip. На Android сохранить файл и открыть браузером, а не текстовым предпросмотром мессенджера. APK не нужен. Реальный Android пока не проверялся.

Подробности: ../docs/WEB_ANALYTICS_079_RU.md и ../docs/MATCH_TELEMETRY_RU.md.

Обновление: python tools/build_analytics.py; python tools/export_analytics_html.py; python tools/package_mobile_analytics.py. Запускать из корня проекта. Проверки: node tests/analytics_static_checks.cjs и node tests/mindmap_core_checks.cjs.

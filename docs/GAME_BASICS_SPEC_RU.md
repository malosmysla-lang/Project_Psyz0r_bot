# «Основы игры» — текстовая спецификация, 10.10.2026

Статус: описано; код и live adapter не реализованы. Общий слой для всех пяти сложностей, стилей, макроигры и оценки результата. Числа из статей не являются конфигурацией сервера.

## Вход и достоверность

Для каждого значения сохранять источник, время, версию режима/карты и known/unknown. Нужны тип игры, фаза (разминка/активный матч/пауза/overtime/завершён), score обоих с поддержкой отрицательных значений, время матча/остаток, timelimit/fraglimit, начисление/потеря очков, ничья/продление/окончание, респаун, предметы, физика. Нужны события начала, паузы, продолжения, завершения, смены карты. Смена карты/матча очищает несовместимую память; пауза не расходует игровые окна и не считается активным боем.

Источники — подтверждённые API/cvars/factory/события конкретного режима, затем проверенные измерения. Конфликт или отсутствие данных даёт unknown, не универсальные10минут или внезапный next-frag overtime. Отделить server-time, active-match-time, оставшееся время и monotonic transport-time. API получения полей ещё не выбран.

## Четыре разных понятия

- Победа: формальный результат режима после подтверждённого завершения.
- Лидерство: преимущество по счёту сейчас.
- Контроль: доступ к ресурсам и выгодным позициям с допустимыми свидетельствами.
- Доминирование: устойчивое преимущество по нескольким наблюдаемым признакам за окно, не один счёт/стек.

## Ограничение приседания

NEW-CROUCH-01: по умолчанию не выдавать crouch. Quiet walk — самостоятельное действие, не приседание. В текущем GameCommand поля crouch нет, но отсутствует и игровой исполнитель: это не доказательство запрета stockAI приседать.

NEW-CROUCH-02, кандидат исключения для джампада: заранее подтверждённый конкретный сценарий карты, нахождение в нужной фазе прыжка и доказанная польза. Прекратить после выхода из сценария/посадки/потери подтверждения. Универсальное приседание на любом джампаде не разрешено.

NEW-CROUCH-03, кандидат исключения для LG: подтверждённая позиция highground за укрытием, своё LG и реальная возможность вести огонь, уменьшив открытость. Прекратить при смене оружия, потере позиции/геометрии/цели или необходимости быстрого отхода. Точные геометрические условия ещё согласовываются; оба исключения до этого не активировать.

Будущий исполнитель обязан журналировать основание исключения и не пропускать crouch вне whitelist. Проверка включает stockAI arbitration, quiet/run без crouch и оба исключения по отдельности. Сейчас это текстовый контракт, изменений поведения нет.

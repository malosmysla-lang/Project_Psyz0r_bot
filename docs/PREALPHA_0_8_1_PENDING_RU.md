# 0.8.1 — исправление перезагрузки VM, пока не развёрнуто

20.10.2026. На сервере остаётся 0.8.0. Проверка присутствия человека остановила попытку выкладки 0.8.1 до любых изменений. Не перезапускать игровой сервер во время тестов.

## Подтверждённая причина сбоя

В 22:27:18 UTC процесс 0.8.0 завершился после перезагрузки qagame:
`ERROR: Failed to hook ClientSpawn: -3`.
В simple_hook.c код -3 означает исчерпание пула из 30 trampoline-слотов.
Наши дополнительные VM hooks откатывали счётчик только в NOPY-сборке.
В Python-enabled сборке стандартный HookVm возвращал свои три слота,
но наши слоты накапливались после каждой перезагрузки VM.

Исправление в adapter/native/psyz_control_lab.h возвращает только количество
успешно созданных наших VM hooks в обеих сборках. Постоянные engine hooks
не затрагиваются. Это исправление жизненного цикла, не изменение силы/точности.

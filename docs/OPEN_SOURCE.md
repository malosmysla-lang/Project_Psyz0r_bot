# Подготовка открытого репозитория

Пользователь поручил вести все этапы разработки в GitHub. Собственный проект подготовлен к публикации: исходники, настройки, ТЗ, история этапов, правила вклада и CI. Локальные референсы сохранены, но исключены из Git вместе с ресурсами и бинарниками; их URL/версии доступны в references/manifest.json.

На момент подготовки удалённый origin не задан, GitHub connector не показал доступных репозиториев подключённого аккаунта. Запрошена ссылка на целевой публичный репозиторий. Создание репозитория недоступно через имеющиеся GitHub connector tools; пароль или токен в чат не требуется.

Пользователь выбрал MIT для собственного кода. Текст сохранён в LICENSE; сторонние проекты и унаследованные ресурсы сохраняют собственные лицензии и не подпадают под MIT нашего проекта. Ссылка на целевой GitHub-репозиторий ещё ожидается.

GitHub Actions подготовлен для Windows/MSVC, CTest и Python unittest; удалённый запуск возможен после публикации. Локальные проверки уже выполнены, но это не подтверждение запуска GitHub CI.

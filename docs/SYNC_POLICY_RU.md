# Синхронизация проекта

Рабочая папка: C:/Users/user/Desktop/Quake SERVER/Project_Psyz0r_bot.
GitHub: https://github.com/malosmysla-lang/Project_Psyz0r_bot, main.
Сервер: /home/qlserver/psyz0r-bot/releases/<commit>-full.

Каждый завершённый этап сохраняется локальным коммитом, отправляется в origin/main и целиком экспортируется git archive HEAD в новый серверный каталог. Архив содержит все отслеживаемые файлы, включая схемы, исходные требования и документацию. Перед распаковкой проверяются SHA-256 и относительные пути. Серверный current-source.txt указывает только актуальную копию исходников, не активирует игру. Git bundle хранит резервную копию опубликованной истории на сервере.

Проверка: локальный HEAD == origin/main == серверный COMMIT.txt, совпали SHA-256 архива и файловый манифест. Если один шаг не выполнен, этап нельзя объявлять синхронизированным. git archive не включает незакоммиченные изменения; перед завершением проверять git status.

Отдельные локальные каталоги out/assets/prototype, загруженные references/* и tools/udt, кэш и секреты не входят в публичный Git-исходник. Демки/исходные сторонние материалы/бинарники требуют отдельного резервного хранения и проверки лицензий; эта синхронизация не заявляет их загрузку. Собственные логические материалы и настройки редактора включены. Ни синхронизация, ни current-source.txt не заменяют развёртывание игрового исполнителя.

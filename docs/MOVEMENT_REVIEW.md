DLL — сторонняя зависимость офлайн-анализа со своей лицензией; MIT нашего проекта её не перелицензирует. Собственный парсер UDT в проект не скопирован. Python читает публичные упакованные структуры C API через ctypes; версия проверяется до разбора. См. [upstream custom parsing](https://github.com/mightycow/uberdemotools/blob/develop/CUSTOM_PARSING.md).

Воспроизведение:

```powershell
python tools/extract_movement.py 'ПОЛНЫЙ_ПУТЬ_К_ДЕМКЕ.dm_91' --output out/demo/movement.jsonl
python tools/review_movement.py out/demo/movement.jsonl --output out/demo/routes.json --match-stats 'ПОЛНЫЙ_ПУТЬ_К_UDT_JSON.json'
```

Демо/UDT JSON и DLL не входят в публичный Git. Для свежего клона DLL надо взять из указанного архива; исходную демку хранить отдельно. --match-stats пока допускает ровно один матч и один непрерывный POV/time segment.

## Следующий шаг

Ручная проверка подходов: успешный/опасный путь, точки входа, открытый отход, видимые столкновения, допустимые прыжки. Затем сопоставление с геометрией карты/графом проходимости, а не слепое копирование координат. Нужны размеченные таймкоды пользователя и демонстрация исполнения маршрута в игре.

Записи от nekitz0r POV не дают непрерывного маршрута PsyRoZ. Нельзя копировать движение PsyRoZ из скрытых/непереданных позиций. Исходные движения мыши и клавиши не подтверждены; viewangles и velocity — наблюдаемые результаты сетевого состояния. В этой итерации навигация бота в QL не исправлена и не проверена.

# Первый просмотр владельцем: профиль не соответствует задаче

Дата: 2026-10-09. Тест завершён по сообщению владельца. Изолированный bloodrun/FFA, UDP27961, профиль Psyz0r_bot со штатным игровым AI; автономный C++ release bc68587 (0.5.0) не управлял им.

## Отзыв владельца

- Бот почти ничего из ожидаемого не показал; чата и реплик нет.
- Движение слабое, рокетджампов не замечено.
- По наблюдению владельца почти не собирает предметы, преимущественно использует перчатку («пилу»).
- После 20+ фрагов владельца начал эффективно использовать рейлган и шафт.
- Оценка владельца: существенно ниже ожиданий, обычный бот Quake лучше.

Это наблюдения владельца, а не измеренные показатели телеметрии. Конкретный финальный счёт, проценты точности и причинная связь изменения оружия со счётом не установлены.

## Что подтверждено технически

В собственных test cfg: bot_nochat=1, qlx_plugins=psyz_state_probe, g_gametype=0. Наш событийный чат не подключён; его отсутствие объясняется конфигурацией и отсутствием интеграции. Включение стандартной болтовни не заменило бы наш чат.

Probe читает собственное состояние, но хранит только последний снимок, а не историю матча. command_sent=false. Новые movement/pressure_escape/tilt/forfeit/difficulty/chat политики не исполнялись в QL. Поздние попадания рейлом/шафтом нельзя считать подтверждением наших состояний или адаптации. Нельзя по имеющимся данным установить причину слабого сбора предметов и выбора перчатки.

В сохранённой консоли нет структурированных Kill/Item/ClientConnect записей. Полноценного поминутного разбора боя, маршрутов и оружия эти логи не обеспечивают. Демка этого просмотра не подтверждена. Доступный последний probe после выхода владельца не доказывает поведение на протяжении матча.

Сохранены console.log, console-final.log, последний psyz_probe.json, server.pid, manifest.json с SHA256; все локальные копии сверены с manifest.

После проверки точного PID/home/порта отправлен quit только изолированному экземпляру. PID129743 завершён, порт27961 закрыт, quakelive.service active, основной UDP27960 остался слушать. Основной бот и конфигурация не изменялись. Консольный архив содержит ShutdownGame при остановке.

## Обязательная следующая работа

1. Подтвердить native исполнитель для выбранного типа агента (штатный серверный бот либо клиент); не выдавать чтение состояния и профиль за работающий собственный бот.
2. На отдельной явной серверной проверке доказать минимальную команду и измеряемый игровой результат: движение, взгляд, прыжок, оружие, выстрел, с аварийным возвратом штатного управления.
3. Добавить журнал входных наблюдений, выбранных решений, отправленных команд и подтверждённых результатов. До матча проверить запись истории и подключение нужных событий, а не только наличие файла последнего state.
4. Подключить событийный чат с проверкой реального отправления, cooldown и защиты от обмена бот-бот. Само снятие bot_nochat не реализует эту задачу.
5. Затем подключать модули по очереди: движение/маршруты ресурсов, выбор оружия/бой, контроль, реакции и состояния. Для каждого отдельная проверяемая демонстрация. Не настраивать «тильт после 20 фрагов» по неподтверждённому наблюдению штатного AI.
6. Следующий полноценный тест в согласованном режиме дуэли, с записью демки/телеметрии и сравнением со штатным ботом на той же карте. Новое развёртывание по отдельной команде владельца.

Итог: просмотр профиля не прошёл критерии тренировочного бота; собственные игровые механики остаются неподключёнными. Этот отчёт фиксирует факты и отзыв, не объявляет исправления выполненными.

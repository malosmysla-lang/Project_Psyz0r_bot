# 0.8.6 — реальный профиль, чат и закрытый стенд

20.10.2026. Обновлён только игровой тест 27961 после двух проверок отсутствия людей. Основной PID 429089 сохранён. Резервные копии: `/home/qlserver/backups/psyz-chat086-20261019T234956Z` и `/home/qlserver/backups/psyz-shadow086-20261019T235127Z`.

## Исправление прежнего вывода о Xaero

Проверки 0.8.2–0.8.5 подтверждали исправленный PK3, но отдельный `baseq3/botfiles/bots/psyz_c.c` перекрывал его. В реально прочитанном старом профиле оставались `psyz_w.c`, JUMPER .05, WEAPONJUMPING 0, AIM_SKILL .85 и другие старые значения. Поэтому прежние заявления о фактически активной точной базе Xaero были неверны; результаты старых контрольных матчей нельзя считать чистым сравнением Xaero с самим собой.

Отдельный файл синхронизирован с проверенным профилем в PK3. SHA-256: `7a2765775614e346eb3761948e8927120b5211d00c3a60aabb3f224e69b22619`. После перезапуска журнал подтвердил загрузку `bots/xaero_w.c` для Psyz0r. Урон за попадание не изменялся. Сила новой версии ещё требует игровых измерений.

## Чат / forfeit

Добавлены реакции на дополнительную RU/EN/транслит-ругань, «как дела», «найди меня» и четыре сообщения за восемь секунд. В ответах нет повторения уничижительных обозначений людей. Ограничение ответов — минимум четыре секунды. «Найди меня» пока вызывает только реплику, а не новую навигационную команду.

Один случайный выбор 35% на матч. Выход разрешён только на 27961, при bot_minplayers=0, одном человеке и одном Psyz0r, через 120 секунд, при отставании 15+ и отсутствии нового фрага 90 секунд либо накопленном gauntlet-уроне 150+. Сообщение предлагает реванш; автоматического повторного входа в тот же матч нет. Событие пишется как PSYZ_FORFEIT в console.log. Доля реальных выходов будет ниже 35%, поскольку сначала требуется выполнение условий.

Проверки: 17 тестов чата, всего 22 теста Psyz-плагинов прошли. Новая игровая реакция и фактический forfeit человеком пока не подтверждены.

## Отдельный стенд

Сервис `psyz0r-lab.service`, порт 27962, отдельные home, конфиг, профиль, журнал и UNIX-консоль. Ресурсы retail подключены ссылками без второй многогигабайтной копии. Пароль владельца хранится только в приватном серверном конфиге. Движок подтвердил g_needpass=1.

Очередь: Xaero–Psy, Psy–Xaero, Psy–Psy; по три минуты / 20 фрагов. Появление человека, включая наблюдателя, запрещает автоматическую замену участников и карты. Для возобновления после такого посещения нужен новый запуск карты. Лимиты стенда: 512 MB и 35% CPU. Измерения с ограничением CPU следует отделять от человеческого теста.

Запущен первый матч; реальные убийства записываются в `/home/qlserver/psyz0r-lab-home/lab-events.jsonl`. Полный круг очереди на момент записи ещё не подтверждён. Финальные PLAYER_STATS предусмотрены, их получение ещё проверяется.

Это стенд измерений, а не автоматическое обучение. Модули прицельного тренинга предметов, перчатки, corpse damage и rocket jump ещё не готовы. Платный AI не подключён, расходов на API нет. Native экспериментальные движения и комбо выключены; стенд пока измеряет базовый профиль.

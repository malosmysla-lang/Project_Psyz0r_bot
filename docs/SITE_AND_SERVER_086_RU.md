## Сайт

Опубликован VPS-выпуск `20261020-086-dashboard-r6`. В шапке убрано вертикальное центрирование левого блока по высокой карточке Connect: `Development Control`, персонаж и заголовок теперь начинаются сверху по одной сетке. Установлены единые нижние отступы у section labels и flow-схем.

Старые автономные HTML/ZIP-выгрузки удалены из текущего web-root. Прямой запрос `Pracc_Room_Server_BOT.html` возвращает 404. Для освобождения места удалены устаревшие неактивные web-релизы с этими экспортами; текущий r6 и предыдущий r5 сохранены. На VPS свободно 676 MiB после операции.

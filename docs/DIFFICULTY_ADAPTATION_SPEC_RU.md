# Пять уровней и адаптация внутри уровня

Дата:10.10.2026. Основание: последнее дополнение владельца в чате. Статус: **текстовое ТЗ и план проверок**, не реализация новых возможностей. Уточняет C13, F07–F09, I01, L01–L12 исходного реестра; повторные требования не создаются. Предварительная градация остаётся предварительной. Оригинальный пакет09–10.10 не редактируется.

## Разделение понятий

1. Базовый уровень1–5 задаёт предел навыков на всю текущую карту.
2. Оценка силы и привычек накапливается по наблюдениям, не одному фрагу.
3. Адаптация выбирает действия и параметры внутри границ этого уровня.
4. Тактический стиль и настроение меняются отдельно и тоже не открывают запрещённых способностей.
5. Между картами уровень может измениться максимум на±1 после оценки полноценного матча и явного согласия на реванш. Новый игрок начинает с3. Одиночноеgg не согласие; без согласия уровень не меняется.

Результат: lvl1 против сильного лучше использует свой простой арсенал решений, а не становится lvl4. Внутриматчевая адаптация не является сменой постоянного уровня.

## Что задаёт профиль

| Область | Обязательные границы |
|---|---|
| Каждое оружие Rail/LG/RL/PG/SG/MG/GL | Отдельные параметры реакции, наведения, сопровождения и упреждения; согласованные диапазоны исполнения |
| Перчатка | Отдельно достижимость контакта, дистанция, реакция и правила мести; не подменять процентом hitscan |
| Мувмент | Разрешённые приёмы/прыжки, освоенные маршруты, качество и допустимые ошибки исполнения |
| Тактика | Набор решений, разнообразие маршрутов, оценка риска, варианты позиции/отхода |
| Оружие и связки | Допустимые переключения, условия комбо, ограничения сложных последовательностей |
| Контроль | Возможности ресурсного цикла и качество его исполнения |
| Spawntrap | Разрешение, отдельные лимиты числа эпизодов и длины каждой серии, условия отмены |
| Адаптация | Предел изменения качества/темпа/выбора внутри данного профиля |

Названия полей будущей структуры ещё не утверждены. Нынешний config/difficulty.json не является полной реализацией этой таблицы: это выключенные профили-предложения. Имеющиеся reaction_ms/decision_interval_ms не утверждаются новым текстом автоматически.

## Предварительная градация

| Уровень | Мувмент и стрельба | Решения и возможности |
|---|---|---|
| 1 I Can Win | Низкая точность, медленная реакция; почти без распрыжки, без сложных триксов; отдельный простой освоенный RJ для доступа к предмету | Простые маршруты, частые пропуски предметов/оружия; без намеренных комбо и spawntrap |
| 2 Bring It On | Базовая распрыжка с потерями скорости, простые изученные RJ; выше реакция и точность | Больше маршрутов, лучше подбор оружия/основных предметов; простые смены оружия, без систематической прогонки |
| 3 Hurt Me Plenty | Полупрофи — целевой образ; уверенная распрыжка, изученные триксы/RJ, боевой стрейф с человеческими ошибками | Комбо, вариативные маршруты, борьба за контроль; возможность1–2spawntrap-эпизодов/матч |
| 4 Hardcore | Быстрое устойчивое движение, больше триксов; лучше aim/tracking/lead | Разнообразные решения, своевременные комбо, наказание циклов и использование окон респауна |
| 5 Nightmare / Кошмар | Лучшее согласованное человеческое исполнение, эффективные прыжки без изменения физики | Лучшие прогноз/контроль/комбо/переключение тактики; ограниченная информация, задержки, ошибки и возможность скрытого обхода сохраняются |

Низкая сложность допускает правдоподобные ошибки решений/исполнения. Технические зависания, бессмысленные вращения и действия не являются способом ослабить бота. Простой RJ уровня1 не разрешает сложные прыжки и не отменяет обычную стоимость HP/armor/ammo.

## Точность через исполнение

- Для всех семи дальнобойных оружий отдельные параметры, без одной общей ручки«accuracy».
- Использовать задержку реакции, погрешность наведения, сопровождения и упреждения.
- Запрещены случайное отключение попаданий, искусственный промах уже попавшего выстрела, изменение damage/физики/HP/hitbox.
- Численные проценты/диапазоны сначала рассчитать по подходящим демкам, описать выборку/семантику попадания и согласовать с владельцем. Настройки сейчас не применяются.
- Фактическая точность зависит от позиции, дистанции и противника. Нет гарантии заданного процента в каждом бою, нет «компенсационных» попаданий/промахов для подгонки статистики.

Параметры адаптации/контратаки/настроения ограничены профилем даже при сильном давлении. Разрешение конфликта C1 о направлении изменения качества в контратаке всё ещё требуется; это дополнение подтверждает пределы, но не выбирает окончательные условия контррежима.

## Адаптация на каждом уровне

Единые условия оценки слабого/сильного/агрессивного/осторожного игрока, окна наблюдений, привычки/волны, контратака, «Крыса» и отсутствие скрытого слежения теперь находятся в [OPPONENT_ADAPTATION_SPEC_RU.md](OPPONENT_ADAPTATION_SPEC_RU.md). Они применяются на всех уровнях в границах профилей выше. Сила и стиль независимы, один соперник может быть сильным и осторожным. Новый блок не разрешает новые проценты попаданий и не превращаетQA-план в выполненные тесты.

## Spawntrap: эпизод отдельно от длины серии

- Эпизод — одна короткая серия давления; его длина — число последовательных перехватов/респаунов внутри серии.
- Уровень1: запрещён. Адаптация не снимает запрет.
- Уровень2: систематическая прогонка запрещена. Разовый намеренный эпизод отдельно не разрешён этой формулировкой; не считать молчание разрешением.
- Уровень3: возможность1–2эпизодов за матч, не минимальная квота; без условий допустимо0. Длина каждой серии ограничена отдельно ранее заданным пределом до2–3респаунов. Конкретные лимиты в этих диапазонах ещё выбираются настройками, не фиксируются этим документом.
- Уровни4–5: лучше использовать подходящие возможности, но численную частоту ещё настроить по демкам/испытаниям. Не назначать автоматически безлимитную прогонку. Ранее заданный предел короткой серии сохраняется, пока явно не изменён.
- Потеря условий прекращает серию. Не «добивать квоту» и не гарантировать фраг/урон.

Это ограничение возможностей, а не доказательство реализации алгоритма respawn или игрового исполнения.

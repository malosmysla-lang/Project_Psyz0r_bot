## Анализ зависимостей

F01 требует реального pickup-сенсора и конечного бюджета попытки. В старом коде
проверка результата учитывает любой недавний предмет либо повышение высоты; это
не подтверждает подбор красного. Начальный подэтап — устранить ложный успех,
после чего оценивать маршруты. Старый экспериментальный навигатор нельзя включать
целиком только потому, что в нём есть код прыжка.

F02/F03/F05 используют единый арбитраж: срочная безопасность → восстановление
боеспособности → достижимый полезный ресурс → подготовка контроля → выгодная атака.
Абсолютные таймеры без времени пути приведут к опозданиям; запрет любого боя
при низком стеке приведёт к беззащитности. Эти два обхода требований не применяются.

F04 отделяет направление взгляда от вектора движения. Для F07 нужно сравнивать
геометрию/скорость и место в маршруте, а не только суммарный поворот камеры.

AI01: подходящий первый исследовательский вариант — обучаемая оценка контекста
и ограниченный выбор среди уже проверенных маршрутов/тактик. Решение об алгоритме
и признаках принимается после проверки доступных сенсоров. Автоматическое обучение
пока не реализовано; перенос человеческой траектории — другой этап.

## Начальные факты

Из сохранённого публичного ledger: 21 матч 0.9.0-rc2 против людей длиной >=300 с.
RA Psyz0r: 15, соперники: 261; в 9 матчах у бота 0 RA. Это описательная выборка,
не доказательство одной причины и не сравнение одинаковых условий/слотов.

Все новые выводы должны иметь ссылку на источник, SHA-256 демки, POV/client,
game state и время. Данные с других карт, с другим gravity/physics или сомнительной
непрерывностью нельзя автоматически превращать в маршрут Blood Run.

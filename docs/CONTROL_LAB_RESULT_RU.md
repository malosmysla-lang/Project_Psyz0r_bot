# Первое подтверждённое управление ботом в Quake Live

10.10.2026. Владелец разрешил перейти к видимому результату на отдельном тестовом сервере. Основной процесс и его файлы не изменены.

## Что проверено в игре

Собственный обработчик перехватывает ClientThink_real только slot0 с флагом серверного бота. Перед физической обработкой меняются pers.cmd: направление, forward/up, кнопки и выбор текущего оружия. Затем вызывается оригинальная игровая функция. Координаты, скорость и здоровье не записываются.

Подтверждено журналом 50 отсчётов после физической обработки:

- остановка после естественного торможения;
- движение вперёд на 280.397 единицы за наблюдаемый интервал;
- углы pitch/yaw = 0/0 через command angles с учётом delta_angles;
- обычный прыжок: ground=1023, высота 408.125 → 455.25 в отсчётах, затем приземление ground=1022.

Частота журнала 100 мс: зарегистрированная максимальная высота не обязательно истинная вершина траектории. Это доказательство исполнения базовых команд, не готовность всего GameInterface.

## Тест для владельца

Подключение: `connect 78.17.9.235:27961`. Карта bloodrun. Бот Psyz0r_bot: режим2 повторяет тест движения с разворотом на 180 градусов через цикл. Это диагностическое движение, НЕ маршрут из демки и НЕ обучение рокетджампу. Стены могут ограничить проход.

Режим1: однократные 5 секунд контроля, затем возвращается штатный AI. Режим2: повторение каждые7 секунд, обычный AI-командный ввод для этого слота заменён. `set qlx_psyzControlMode 0` отключает контроль и сбрасывает начало; управление возвращается штатному AI. Боты/живые игроки других слотов не затрагиваются. Смерть отключает обработку в мёртвом состоянии. Это лабораторный режим, не для обычных дуэлей.

Контроллер работает только при env PSYZ_CONTROL_LAB, qlx_psyzTestInstance=1, net_port=27961, mode1/2 и совпадении проверяемых ABI. Тестовый отдельный home: /home/qlserver/psyz0r-bot/control-lab-20261010/home. Основной порт27960 не менялся.

## Следующий шаг

Реальный базовый путь команд больше не полностью заблокирован. Остались attack/смена оружия, считывание состояния в общий адаптер, управление взглядом с ограничением скорости и согласованный арбитраж жизненного цикла. В текущем тесте взгляд намеренно фиксирован для проверки.

Далее: один старт и цель из успешного эпизода ZTN; наведение и короткий импульс jump+attack; проверка попадания ракеты в поверхность, HP/брони и приземления. Демка показывает состояния, не исходный usercmd: восстановленные команды должны быть помечены как гипотеза и проверены в физике сервера. Рокетджамп и маршрут из демки пока не выполнены.

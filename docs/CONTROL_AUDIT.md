Предпочтительная проверяемая гипотеза — серверный бот с собственным usercmd-перехватом. Решение пока не принято: WinQLX32 без расширения API не обеспечивает обязательные пять действий. Альтернатива — клиентский ввод, но нужен самостоятельный подключённый клиент и проверка его состояния; RCON не заменяет usercmd.

Найдена установленная retail Quake Live в C:/Program Files (x86)/Steam/steamapps/common/Quake Live. Найден также соседний quake-admin с адресом действующего сервера. Он не использован: пользователь требует отдельный тестовый сервер, а статус найденного сервера как тестового не подтверждён. Настройки запуска/перезапуска рабочего сервера не менялись.

Для продолжения ожидается выбор тестового окружения. Если локальное — изолированная папка, другой порт, отдельные логи и конфиг. Если удалённое — отдельный адрес/порт, путь и доступ. Предварительно проверить версию бинарника, архитектуру, map/base assets и загрузку расширения, затем тестировать каждое действие с остановкой между шагами. До этого нет заявления о реальном управлении.

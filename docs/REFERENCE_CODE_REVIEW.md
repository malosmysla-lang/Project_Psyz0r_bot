# Первый разбор исходников референсов

9 октября 2026. Проверено локальным чтением скачанных файлов. Сборка и игровая проверка не проводились.

## Штатный Q3

- `references/quake3-source/code/game/ai_main.c`: BotInputToUserCommand на строке 818, вызов на 916; BotAIStartFrame на 1377; trap_BotUserCommand на 1419/1559. Это точки преобразования решения в команду и передачи её движку.
- `code/game/ai_dmq3.c`: BotChooseWeapon на 1566; BotWantsToRetreat на 2268; BotWantsToChase на 2321; BotEntityVisible на 2825.
- Прочитанная функция отхода учитывает режим/цель, а затем BotAggression <50. Это не наше правило «получил 70–100 урона в боевом эпизоде»; для него потребуется отдельная память эпизода и более подробная оценка своего состояния.

## Brainworks

Проверены отдельные модули, что подтверждает наличие кода соответствующих подсистем, но не качество поведения:

| Подсистема | Файл | Что найдено |
|---|---|---|
| Наблюдение | code/game/ai_scan.c | Обработка EV_FOOTSTEP, EV_FIRE_WEAPON и звуковых событий. Нужно разобрать фильтры слышимости и видимости. |
| Память о врагах | code/game/ai_aware.c | Список записей awareness с временем и обновлением. Кандидат для изучения памяти последнего наблюдения. |
| Уклонение | code/game/ai_dodge.c | BotDodgeMissile оценивает близость траектории и риск splash при вариантах уклонения. |
| Предметные цели | code/game/ai_pickup.c | max_respawn/soonest_respawn, BotRecomputeItemGoal и оценка цепочек целей. Не установлено, какие сведения игроку доступны и нет ли лишнего знания. |
| Оружие | code/game/ai_weapon.c | WeaponInRange, WeaponBlast и другие оценки применимости/урона. Полное решение выбора оружия ещё не прослежено. |
| Движение | code/game/ai_move.c, ai_motion.c, ai_path.c | Файлы присутствуют; детальный разбор strafejump и расхода HP ещё не выполнен. |

Предварительный вывод: архитектура Brainworks подходит как референс разделения наблюдения, памяти, движения и решений. Это наша оценка применимости, а не результат игровых тестов.

## ioquake3

`references/ioquake3/code/server/sv_bot.c` содержит вызовы botlib_export и настройку библиотеки ботов. Вместе с Q3 ai_main это позволяет исследовать границу game module ↔ engine. Наличие такой границы в открытом Q3 не подтверждает аналогичный внешний интерфейс QL.

## Что изучать дальше

1. Q3ABotEdit и работа van Waveren по ранее согласованному порядку чтения.
2. Проследить Brainworks scan → aware → goal → weapon → command на одном игровом кадре.
3. Разобрать происхождение информации о подборе предметов и допустимую память без WH.
4. Сопоставить эти решения с доступными snapshots наших dm_91 через UDT.
5. Определить реальный интерфейс собственного контроллера в Quake Live до выбора окончательной архитектуры сборки.

# Преальфа 0.6.3: готова для проверки владельцем

11 октября 2026. Область прежняя: маршруты/подходы, предметы, ограниченная распрыжка, RJ, существующие дебюты. Другие поведенческие блоки не добавлены.

Исправлена потеря подключения модулей после нескольких загрузок qagame. В NOPY-адаптере наши три VM-перехватчика расходовали ограниченный пул trampoline-слотов. Теперь перед установкой на новую выгруженную/перезагруженную VM переиспользуются только успешно занятые нами слоты; постоянные engine-перехватчики сохраняются. Исправление относится к текущей NOPY-сборке, не заявляет поддержку произвольных minqlx-конфигураций.

## Дополнительные игровые прогоны

На финальном бинарнике выполнены три дуэльных прогона по 40 секунд и две отдельные принудительные RJ-пробы по 30 секунд. Журнал каждого включает загрузку карты; проверены SHA журналов, реальные события и отсутствие ошибок перехвата. Отчёт: `training/PREALPHA_0_6_3_TRIALS.json`.

| Прогон | Реальные подборы | Результат |
|---|---:|---|
| Duel 1 | 7 | Дебют отменён: нет проверенной цели |
| Duel 2 | 11 | Первый шотган взят; следующая цель не подтверждена; зарегистрирован fallback к AAS |
| Duel 3 | 7 | Жёлтый и Мега взяты; третья цель недоступна/далеко |
| RJ sample 0 | 3 | Прыжок успешен: первый выход выше на 129 единиц и полезный подбор |
| RJ sample 1, экспериментальный | 5 | Прыжок успешен: первый выход выше на 184 единицы; полезного подбора в событии нет |

Итого: 33 фактических подбора, 17 записей strafe-команд, 2 успешных RJ, 0 ошибок подключения модулей. Это не доказательство оптимальности маршрутов или 17 удачных распрыжек. В этих трёх дуэлях полного порядка из трёх предметов не было.

В предшествовавшей серии 0.6.2 отдельно подтверждён полный дебют: rocket → yellow → mega, план 17. Затем серия выявила исчерпание hook-слотов; прогоны без подключённых модулей не считаются успешными. Подтверждённый отдельный прогон сохранён в `training/PREALPHA_0_6_2_COMPLETED_OPENING.json`.

RJ sample 0 остаётся единственным автоматически разрешённым. Sample 1 имеет один успешный принудительный прогон: этого недостаточно для автоматического включения. Ещё 14 наблюдавшихся RJ пока не прошли live-проверку.

## Как зайти

```
/connect 78.17.9.235:27961
/ready
```

Карта — обычный Blood Run, бот в слоте 0. Принудительные RJ-пробы отключены (`qlx_psyzRJProbe=0`), дебюты и преальфа включены. Основной сервер 27960 не изменялся.

Для фидбека записывай демку и отмечай: первая пушка, следующие предметы, где застрял, где прыгнул без пользы, что сделал при перехвате предмета. Главные известные ограничения: не все проверенные botlib goals сопоставляются с дебютными целями; отдельные подходы срываются; оптимальность распрыжки не измерена; автономный выбор RJ против человека не доказан.

Локальная Windows-сборка проверяет ядро/сценарии MSVC. Игровой перехватчик собран отдельно для закреплённого Linux QL. Это тестовая преальфа, не завершённая Mind map.

# 0.7.1 — игровой чат Psyz0r

## Причина молчания

Тестовый 27961 работал на `minqlx_nopy.so`: C++-модули загружались, Python-плагины — нет. В конфиге также стоит `bot_nochat 1`, чтобы штатный QL-бот не спамил стандартными фразами. Локальная `runtime/chat.py` была только проверяемой политикой без игрового адаптера.

Рабочий `room_bot.py` основного Xaero скопирован в `server/minqlx-plugins/room_bot.py` как исходная реализация для сравнения. Основной серверный файл не изменялся. Для тестового бота создан отдельный `psyz_chat.py`: он не добавляет, не удаляет и не переименовывает ботов, а работает только при составе один человек + один бот Psyz0r.

## Подключённые события

- гарантированное `GL/HF` перед дуэлью;
- взаимные ответы на `GL`, `HF`, `good luck`, `have fun`;
- ответ на `GG/WP` и отдельная спортивная реплика после завершённой дуэли;
- похвала, когда человек убивает Psyz0r; отдельная фраза для рейла;
- редкие подколы после убийства человека рейлом или ракетой;
- одна ограниченная реакция на грубость за матч;
- редкая периодическая реплика не чаще одного окна в 180 секунд и только с вероятностью 35%; спам про предметы и оружие не включён;
- реакция на подтверждённое убийство Psyz0r перчаткой;
- команда владельца `!psychat` для ручной проверки вывода.

Все сообщения идут от имени `Psyz0r` через плагин. `bot_nochat 1` намеренно сохранён: он отключает штатную болтовню, а не новый чат.

## Ограничение пилы и трупов

Версия установленного minqlx не имеет Python-hook `damage`. Поэтому накопление 25/50 HP урона перчаткой пока остаётся проверенной локальной функцией, но не получает live-событие. В игре подключена только реакция на убийство перчаткой из `death`. Стрельба по трупам также не имеет достоверного Python-события. Эти два входа нужно вывести из нативного qagame-сенсора; выбор оружия и ответные действия C++ от этого этапа не объявляются подключёнными.

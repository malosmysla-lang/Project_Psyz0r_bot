## Причины в коде и внесённые изменения

1. **Ослабленный character вместо боевой базы Xaero 5.** Было attack/aim skill .85, view factor .8, maxchange 240, reaction .20, projectile aim skill .8. Теперь attack/aim .95, view 1.0/360, projectile aim skill 1.0 по установленному Xaero skill 5. Реакция оставлена человеческой .12; crouch=0, обычный jumper=.25, weaponjump=0: специальные RJ остаются нашим исполнителем. Свои веса оружия сохранены. Полный diff и SHA — `training/XAERO_PROFILE_078.json`. Это профиль QL, а не заново написанный AI.
2. **Остановка при защитном MG-огне.** `forwardmove=0` при недостатке Trinity убран. Штатные ходьба, прицел и выстрел сохраняются; недобор оружия повышает ресурсные приоритеты, но не превращает защиту в AFK. Полноценная осмысленная модель отхода ещё требует работы.
3. **Заниженные свободные основные предметы.** Раньше recovery давал Mega 65, RA 55 против YA 160. У свободной Mega и нужного RA поднят приоритет, а gate «две пушки» сохранён для ещё не появившихся предметов, но снят для уже лежащих. При HP<40 принудительный приоритет RA отключён; полный стек не гоняется за лишним бронежилетом. Больший чужой стек сам по себе не даёт сведений о его позиции.
4. **Сторож только при запросе цели и сброс при смене item.** Добавлен отдельный motion-watch на каждом think. Радиус 32u, 1,8с реальной остановки, ограниченная пауза на бой/ожидание. При срабатывании 3с не вмешиваемся в штатное движение/AAS, плохой маршрут и цель получают cooldown. Это локальная память ошибок, не нейросеть. Ждать под красным из-за одной близости нельзя.
5. **Предположение о слоте 0.** Goal/movement/aim/pickup определяют Psyz0r по bot flag и очищенному имени. Человек в слоте 0 не записывается как бот, а Psyz0r в другом слоте не теряет надстройку. Xaero при сравнении не модифицируется.
6. **Чат.** Исправлена проверка Python object identity на Steam ID/слот. Добавлены нуб/nub/noob и RU/EN темы; нет блокировки retort до конца матча. Короткий контекст 45с, пауза между пользовательскими ответами 4с, избегаем последней реплики. Метки #bot и команды исключены. Это ограниченная тематическая система, не языковая модель. Корпус предложений английский, русский ввод понимается.

## Точность победителей: новый ориентир

Из 500 профессиональных демок найдены 478 матчей с однозначно сопоставленным именем победителя и строкой scoreboard. У большинства файлов нет полной оружейной таблицы: поэтому N для конкретной пушки меньше 478. Исключены отсутствующие поля и shots=0, а не заполнены нулями. Среднее — арифметическое reported accuracy по матчам победителей; pooled = сумма hits / сумма shots отдельно.

GL исключён из новой процентовки. Для перчатки нет положительных shots, процент не придумывается. Проценты accuracy не равны урону: splash/SG имеют свои правила учёта. Диапазон ±7,5 процентного пункта влияет на дополнительную ошибку наведения. **Это цели калибровки, не гарантия фактического процента.** Урон пули, число pellets, projectile и hit-result не меняются.

У каждой пушки отдельный `qlx_psyzAimErrorN`: MG .35°, SG .6°, RL .8°, LG 1.25°, RG .35°, plasma 3°. Для MG прежняя общая ошибка уменьшена; одновременно возвращено качество stock-наведения. Дистанция/движение цели и LG-context продолжают влиять. После человеческих тестов сверить фактические hits/shots, особенно LG 5%/16% в прежних матчах.

## Что с обучением Xaero

У открытого Q3 действительно есть отдельный genetic/interbreeding режим для fuzzy weights: `BotInterbreedBots`, `BotInterbreeding`, явные bot_interbreed cvars. Это не доказательство, что штатный Xaero QL постоянно обучается конкретному человеку во время обычной дуэли. Нативный QL AI закрыт; такую возможность не заявляем. Проверенный первичный код: [id Software, ai_main.c](https://github.com/id-Software/Quake-III-Arena/blob/master/code/game/ai_main.c). В этой версии добавлена ограниченная память плохих маршрутов, не имитация доказанного онлайн-обучения.

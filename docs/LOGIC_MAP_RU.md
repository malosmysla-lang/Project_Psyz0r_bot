# Текстовая схема для сверки — 10.10.2026

**Центр:** Psyz0r_bot — ровные по качеству, напряжённые и интересные тренировочные дуэли с подстройкой внутри всех пяти сложностей. Правила + примеры из демок + характер. Счёт не выравнивается принудительно, очевидное добивание не запрещается.

Это новая рабочая текстовая редакция, не замена оригиналов. Полный реестр153 получен и сопоставлен. [Оригинал09.10](Project_Psyz0r_logic_mindmap.png) и [обновлённаяPNGv3 10.10](logic_archive/owner_package_2026-10-10/Psyz0r_bot_map_4K_v3.png) сохранён без изменений; старые подписи читаются с уточнениями из [сверки](LOGIC_RECONCILIATION_RU.md). [Таблица статусов](REQUIREMENTS_TRACEABILITY_RU.md) показывает пробелы каждой ветви. Ни одна ветвь исполнения нашего поведения не подтверждена в QL.

**Общая база NEW-BASICS:** реальные правила/фазы/лимиты/время/overtime → смысл счёта и допустимый риск для всех ветвей. [Текстовый модуль](GAME_BASICS_SPEC_RU.md). NEW-CROUCH: запрет по умолчанию, только два конкретно согласованных исключения; тихий шаг отдельный.

**Цикл принятия решения:** подтверждённые правила и свои данные → допустимые наблюдения/память → оценка силы/стиля/контроля с неопределённостью → ограничения уровня → арбитраж состояния/тактической цели → маршрут/оружие/стрельба/событийный чат → исполнитель → наблюдаемый результат и журнал → новые наблюдения.

**Текущий разрыв:** переход от предложения к игровому исполнителю отсутствует. Probe не выполняет команды. Ни профиль skill5, ни тесты sandbox не заменяют этот переход.

**Уточнение уровней по PNG, ещё не исполнитель:** L1 почти без распрыжки, простой RJ, без дополнительных триксов/spawntrap; L2 базовый strafe с потерями и простой RJ/смены оружия; L3 half-beat, триксы/комбо и до1–2spawntrap-эпизодов; L4 лучше движение/решения/прогноз; L5 максимум согласованного человеческого исполнения. Это подробнее нынешних профилей JSON; ограничения из полученного реестра сопоставлены поL01–L12, но ещё не применяются в игре.

**История редакции:**09.10 PNG →10.10 текстовая версия с новой центральной целью, запретом обычного crouch, основами игры, отмеченными C1–C4 и пробелами. Полный реестр получен в ходе сверки:153 исходныхID сохранены. ВременныеAUD-ID остались только в рабочем архиве, основная таблица использует A01–L12.

Дополнение владельца10.10: [единая спецификация сложности](DIFFICULTY_ADAPTATION_SPEC_RU.md) уточняет ветвьL и связанныеC/F/I. Адаптация на каждом уровне, независимые бюджетыspawntrap, отдельные weapon параметры иQA-план. Оригинальные схемы сохранены.

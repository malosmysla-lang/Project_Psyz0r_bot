# Проверка пути снаряда

Локальный C++ этап после CombatPredictor: check_shot_path проверяет отрезок от muzzle до aim_point по подтверждённому набору SolidBox. Пересечение считается методом интервалов по осям. Коробки расширяются на projectile_radius; касание считается препятствием. Это консервативная аппроксимация, не BSP-трассировка Quake Live.

Возвращаются Clear / InvalidInput / UnknownGeometry / StaleGeometry / TooClose / Blocked. Проверяются возраст геометрии, конечность чисел, границы коробок, нулевая длина и минимальная дистанция попадания. Пустой набор препятствий не считается свободным без coverage_verified. Этот флаг должен означать полное покрытие пути, включая относящиеся к нему динамические препятствия.

Clear означает лишь прохождение данной геометрической проверки. Это не разрешение attack: отсутствуют выбор оружия, ammo/cooldown, ограничения прицеливания, полная оценка splash/self-damage и игровой исполнитель. minimum_impact_distance — заданный вызывающей стороной предел, не доказательство безопасности от взрыва. Геометрия карты не извлекается этим модулем. Положение собственного игрока после запуска снаряда пока не прогнозируется.

Проверено MSVC Debug/Release: в каждой конфигурации 8/8 групп CTest. Новые сценарии: неизвестный/устаревший набор, препятствие на пути, параллельный проход, касание радиусом, препятствие за целью/позади старта, старт внутри solid, близкая цель, неверные числа/коробки. Интеграционный сценарий доказывает: математически верный перехват CombatPredictor не проходит стену.

Далее: источник проверенной карты/trace, контроллер плавного прицела и отдельное решение о выстреле. В игру модуль не подключён, сервер не перезапускался.

## Хранение и доставка

Локальная папка — рабочий источник. GitHub получает завершённые коммиты после настройки origin. Сервер получает архив собственных src/include/config/runtime/adapter/tests/tools и документов сборки в новый каталог releases/<commit>, без замены основной службы. Проверять SHA-256 до распаковки. Windows exe не являются Linux серверной сборкой.

10.10.2026: GitHub connector подтвердил аккаунт malosmysla-lang, список доступных репозиториев пуст; требуется адрес или создание репозитория. Загрузка и публикация ещё не выполнены.

# Чат Psyz0r_bot

Актуальное ТЗ сохранено в CHAT_SPEC.md. Официальное имя — `Psyz0r_bot`. Источник согласованных текстов — `config/chat.json`; runtime/chat.py читает его без генерации новых фраз.

## Реализовано локально

| Категория | Доступных реплик |
|---|---:|
| Старт | 3 |
| Обычные подколы | 15 |
| Редкая категория R + C | 16 |
| Похвала после смерти бота | 6 |
| Убийство соперника | 4 |
| Завершение/уход | 6 |

Всего 56 доступных реплик: добавлены по три Gauntlet/corpse реакции. Периодические подколы по умолчанию выключены; событийная политика описана в EVENT_REACTIONS.md. Доступность зависит от события: P06 только railgun, P04 исключается для владельца, K01 только railgun, K02–K04 только ракета, E01–E05 по официальному результату. J01 сохранена отдельно как неактивная: детектора рокетджампа нет. Только R11 содержит $100. T06 использует согласованное «one bad decision».

Общий интервал 20 секунд; периодическая проверка 150 секунд с вероятностью 0 по умолчанию. Weapon/item реакции .1 и общий тематический интервал 120 секунд, Gauntlet .7/30.  Из изученного room_bot.py сохранена вероятность редкой категории 1/6, а не резервные 20%; добавление пяти C-фраз её не увеличило. Существующая вероятность похвалы была фактически 100% для подходящих событий вне общего cooldown; она сохранена в настройке praise_probability=1.0. Редкая реплика — максимум одна за дуэль. Повторы исключены, неизвестный соперник исключает тексты с подстановкой. SteamID владельца взят из существующего проекта: 76561197961758497; он настраивается в config/chat.json.

Цвета используют существующий формат ^1/^3/^4/^7. Стартовые сообщения полностью красные; ник владельца синий, остальных соперников жёлтый. Цвета исходного ника удаляются. Фиксированные имена, оружие и ключевые слова окрашиваются по ТЗ, цвет сбрасывается в белый.

Политика разрешает события пакетно: corpse reaction > gauntlet reaction > final > opening > death reaction > periodic (end отменяет незавершённые реакции). Идентификатор дуэли подавляет повторный start, ID события подавляет дубли death, end обрабатывается один раз. Реакции при cooldown отбрасываются; только однократная corpse reaction ожидает до 30 секунд, финал/старт имеют отдельные сроки. Финал ожидает cooldown не дольше 25 секунд (выбранный начальный срок актуальности); cancel отменяет его при смене карты, уходе соперника/бота. E06 заменяет результат. Неизвестный или прерванный результат не создаёт победную реплику.

## Границы реализации

Это независимый Python-модуль политики чата для серверного адаптера, а не C++ контроллер движения. Подключения к minqlx и игровому серверу пока нет. Публичные методы start/death/end/tick/cancel требуют от адаптера проверенных событий: активной дуэли бот–человек, оружия, официального результата, присутствия бота и времени активной игры без пауз. Сам модуль не наблюдает игровой мир и не знает скрытых HP.

PK3 содержит профиль с новым именем и нулевыми вероятностями штатного чата; это намерение настроек, а не подтверждённое подавление движком. Согласованный JSON и Python-модуль не включаются в PK3: их будущий серверный адаптер будет установлен отдельно. Ready/GG из старого файла чата удалены. Сторонние пакеты и демки сохраняют оригинальные имена и содержимое.

Соседний `C:/Users/user/quake-admin/minqlx_plugins/room_bot.py` изучен только чтением и не изменён. Обнаруженные там устаревшие пулы не входят в новый config/chat.json. Развёртывание, рестарты и изменения игровой механики не выполнялись.

## Проверки

`python -m unittest discover -s tests -v` проверяет состав реплик, $100, цвета, исключение P04, неизвестного соперника, дедупликацию, cooldown, приоритет финала, замену уходом, отмену/истечение финала, лимит редкой категории и сброс состояния. Проверка сервера нужна для реальных hooks, доставки цветов/кириллицы, определения оружия, результата, корректности SteamID и отключения штатного чата.

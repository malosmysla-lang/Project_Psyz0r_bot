# Обновление логики и графики

19.10.2026. Действующее требование владельца: новые вводные и подтверждённые результаты не должны оставаться только в чате.

1. Записать условие → действие → исключения → проверку, источник и дату. Сохранить существующий ID либо добавить новый в подходящую ветку A–O.
2. Различать изменение требований и продвижение реализации. Данные/написанный код/локальные тесты/интеграция/игровой результат — отдельные свидетельства. Не повышать статус автоматически.
3. Обновить текущий MD-реестр, прослеживаемость и CHANGELOG/PROJECT_STATE. При смене версии сохранить прошлый комплект.
4. Сгенерировать графику, OPML, HTML и JSON. Проверить сохранность прежних ID, полноту текста, перенос переполнения, размеры, кодировку, XML и ссылки.
5. Просмотреть изображения, сохранить SHA-256, сделать отдельный коммит и push; серверную документационную копию держать отдельно от runtime.

Текущая карта: [v5](mindmap_v5/index.html), [источник](MINDMAP_V5_CONTENT_RECONCILIATION_RU.md). `tools/update_logic_v5.py` воспроизводит переход v4→v5; `tools/generate_mindmap_v5.py` строит изображения из MD v5. Последующие ручные дополнения v5 не затирать повторным запуском переходного скрипта без переноса их в источник.

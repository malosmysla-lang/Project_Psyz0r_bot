# Дополнение к Mind Map: 19.10.2026, версия 0.7.4

Исходная карта v4 остаётся документальным срезом 12 октября. Эти уточнения относятся к её веткам D/E/H/I/N/O и не переписывают исходную переписку.

| Ветка | Условие → действие | Статус и проверка |
|---|---|---|
| D: восстановление | Неподвижность <=8 units в течение 1,5 с, нет боя/ожидания → demo-route уступает AAS; повторный провал → временный отказ от цели | Код и native-тесты; в финальном smoke одно восстановление, полное отсутствие застреваний не доказано |
| D/I: красный | Цель красного временно запрещена навигацией → дебют не может выбрать её до конца cooldown | Код и отдельный тест; обязательное прибытие не оправдывает бесконечный провальный маршрут |
| I: выбор дебюта | Подходящая наблюдаемая стартовая область и реальные предметы → кандидат с основным оружием; меньшее время/потеря HP предпочтительнее | 48 кандидатов, 42 с основной пушкой, 0 неверных статических назначений; глобальная оптимальность не доказана |
| H: восстановление | Недостаточный стек/нет оружия/соперник сильнее по доступному стеку → приоритет вторичных ресурсов и пушек | Начальные веса целей подключены; намерения «прятаться» и безопасные позиции ещё не подтверждены |
| H: опорный предмет | Средний стек → выбранная доступная/скоро появляющаяся Мега или красный удерживается как ресурсный anchor до 15 с | Код и локальные тесты; не исключает обязательный дебют, срочное восстановление и навигационный запрет |
| H: цикл | HP>=120, armor>=80, >=2 готовых Trinity → повышается полезность вторичных ресурсов и патронов | Начальный ресурсный режим; не гарантирует тотальный контроль карты |
| E: разгон | W+боковой стрейф → согласованный yaw с правильным знаком rightmove; первый прыжок после разгона, второй/третий по приземлению | Геометрия исправлена и тестируется; фактический эталон скорости бота ещё не достигнут/не подтверждён |
| E: эталон | Полное 4-секундное окно без явного боя/разрыва → максимум наблюдаемой скорости, допуск ±15 UPS | 129 эпизодов, 72 полных окна, кандидат 651,184 UPS; совместимость физики не доказана |
| N: источники | 500 новых уникальных демок → SHA/protocol/source/наблюдения; старые протоколы конвертируются в отдельные копии | 500/500 разобраны; новых Agent26, каталог содержит72 подходящие записи, цель100 не выполнена |
| O: сравнение | Подтверждённые два бота на одной карте → короткий прогон со счётом/подборами/ошибками | Финальный smoke: 25 подборов, один основной, два шага дебюта, счёт1:2 до сброса; победа не заявляется |

Полная спецификация этапа: [PREALPHA_0_7_4_RU.md](PREALPHA_0_7_4_RU.md). Наблюдаемая статистика не заменяет подключённый игровой исполнитель.

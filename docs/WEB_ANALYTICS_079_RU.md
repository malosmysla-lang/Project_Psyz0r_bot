# Pracc Room Server BOT — дашборд и пересылка

Выбранная основа — локальный Tabler Dark 1.6.1/MIT. Два аналитических акцента: бирюзовый и фиолетовый; текст увеличен. Цветной BOT добавлен в название. Рисунок фона не повторяется: фиксированный viewport-слой, прокрутка контента поверх него. Анимации графиков/появления отключаются по prefers-reduced-motion.

## Что показывает

- 700 SHA-уникальных разобранных оригиналов из локального стека 1167; выборка победителя и лидера урона раздельная.
- 284 микро-правила, 15 веток. Интерактивное дерево использует DOM/SVG, а не картинку. Перенос узлов/фона, масштаб, поиск, фильтр, мини-карта, полный экран, сохранение раскладки и экспорт JSON. Полный текстовый реестр остаётся доступным отдельно.
- Гистограммы точности, сравнение когорт, разгон, ресурсные переходы и ограничения доказательств.
- 0.7.9 и три предыдущих этапа 0.7.6/0.7.7/0.7.8; 0.7.7 отмечена как офлайн. Число правил/демок/тестов — показатели разработки, не сила бота.
- Отдельный реестр матчей: Psyz0r и архивный Xaero. Счёт, версии, damage, RA/MH/YA, доступная accuracy; выбор строки раскрывает обе стороны по оружию и ресурсам. Есть линия разницы счёта, столбцы, круговые диаграммы и фильтр human/bot.
- Автосбор и границы индикатора обучения описаны в [MATCH_TELEMETRY_RU.md](MATCH_TELEMETRY_RU.md). Автообучение не заявлено.

## Файлы

`Аналитика разработки бота/index.html` — редактируемый сайт с соседними JS/CSS/data. `Pracc_Room_Server_Analytics.html` — компактная однофайловая панель для проекта; ссылки на исходники используют соседние файлы.

`Аналитика разработки бота/Поделиться/Pracc_Room_Server_BOT.html` — полностью переносимый файл со встроенными JS/CSS, данными и скачиваемыми исходными вложениями. `out/share/Pracc_Room_Server_BOT_0_7_9.zip` — этот HTML, JSON, инструкции и обе лицензии. Файлы исходников не требуют отдельной папки у получателя.

На Android сохранить HTML из мессенджера и открыть браузером. Если встроенный просмотрщик показывает текст или блокирует JS, выбрать «Открыть с помощью» → браузер. APK/установка приложения не нужны. Реальное Android-устройство в этом этапе не проверялось.

Офлайн работает встроенный снимок. При интернете раздел дуэлей может читать опубликованный JSON, поэтому новые матчи не требуют повторной установки HTML. Сайт не управляет сервером. Статистика не обновляется тайно через выдуманные значения.

## Сборка и проверки

```text
python tools/update_logic_v9.py
python tools/generate_mindmap_v9.py
python tools/build_analytics.py
python tools/export_analytics_html.py
python tools/package_mobile_analytics.py
node tests/analytics_static_checks.cjs
node tests/mindmap_core_checks.cjs
```

Математика карты проверяет все ID, фильтры, сохранённые координаты, zoom anchor, fit и границы гистограмм. VM исполняет встроенные скрипты обычного и переносимого HTML. Проверены ZIP CRC и отсутствие внешних JS/CSS/src-ресурсов. Браузерная визуальная проверка недоступна: CUA вернул пустой список браузеров. Это ограничение не подменяется утверждением о проверке реального телефона.

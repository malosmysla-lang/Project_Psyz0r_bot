## Проверка работающей игры

Активный сервер не перезапускался, server.cfg и загруженные плагины не изменялись. Текущий room_bot_state.json в fs_homepath показывает human_count=1; файл обновлён в ходе диагностики. Это состояние плагина, не полный список соединений из status.

RCON включён и TCP-порт на localhost слушает. Пробы REQ и DEALER, регистрация по имеющемуся zmq_rcon.py, identity и запрос status пока не вернули консольный вывод. В журнале видны ZAP-авторизации/отказы, но успешная авторизация не подтверждает исполнение команды. Пароли не выводились и не включены в проект. Причина отсутствия ответа не установлена; не объявляем сервер недоступным для игроков по этому признаку.

Исходники установленного minqlx доступны в /home/qlserver/build/minqlx, commit fbdd915185337791d8e209dc4b686a1ee60d3721. Проверены player_state, client_command, console_command и hook G_RunFrame. client_command — строковая клиентская команда, не usercmd движения. Поддержанный путь движения/взгляда/прыжка/выстрела в Python API не найден. Нативное расширение необходимо исследовать и проверять отдельно, без угадывания адресов функций на живом сервере.

Следующий игровой этап: получить работающий канал консоли/наблюдения, дождаться свободного сервера для загрузки пробника, затем проверить свой slot state и выбранный нативный путь usercmd. Наличие собственного клиента и управление штатным серверным ботом по-прежнему рассматриваются отдельно.

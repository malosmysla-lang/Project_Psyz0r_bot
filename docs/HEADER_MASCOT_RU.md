# Анимация шапки сайта — 19.10.2026

## Реализовано

- Детальный прозрачный Doom Marine в бирюзово-белой броне, с фиолетовыми акцентами и рокетлаунчером по форме Q3. Это сгенерированная иллюстрация по референсам владельца, не извлечённая игровая 3D-модель.
- Исходник: `Аналитика разработки бота/assets/doom-marine-strip.png`, 2172×724, четыре равные ячейки: стойка, подготовка, прыжок, отдача.
- Одна сцена после загрузки страницы: ожидание → подготовка → прыжок → выстрел → полёт → вспышка у карточки этапа → приземление. Контур карточки гаснет за 1300 мс. После приземления непрерывно поднимается лёгкий дым из ствола.
- Дуга имеет 20 опорных положений с интерполяцией Web Animations. Это не 20 отдельно отрисованных кадров персонажа; поз четыре. Повторяющийся таймер выстрела удалён.
- Угловую голову заменяет собственный векторный механический глаз с радужкой и металлическим ободом.
- `prefers-reduced-motion` оставляет неподвижного персонажа без дыма и выстрела. При печати декорации скрыты.
- Фон остаётся единым fixed-слоем размером с экран, `no-repeat`; эффект не добавляет высоту документу.

## Источники и проверка

Референсы персонажа и механического глаза предоставлены владельцем. Оружие: [подборка форм и текстур Q3 rocket launcher](https://www.moddb.com/mods/cz45modbundle/images/hd-weapon-re-texture-version44); чужие изображения оружия не включались в сайт.

Генерация встроенным image_gen, прозрачный фон. Нормализованный prompt: full-body classic Doom Marine, four horizontal equal cells, facing right, standing/crouch/jump/recoil, consistent model and launcher, pearl white/turquoise armor, violet accents, charcoal undersuit, detailed armor seams and metallic shading, Quake III rocket launcher, no background/text/flash/smoke (effects supplied by code).

Синтаксис JS, проверки структуры дашборда и автономного HTML прошли. Просмотр исходного PNG выполнен. В текущем окружении браузерные поверхности недоступны; визуальное воспроизведение сцены и проверка на телефоне пока не подтверждены. Изменения не затрагивают игровой сервер.

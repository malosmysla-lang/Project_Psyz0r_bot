# Psyz0r_bot

Локальный этап 0.3: [событийные реакции](docs/EVENT_REACTIONS.md), [pressure_escape](docs/PRESSURE_ESCAPE.md) и [разбор движения/58 подходов к предметам](docs/MOVEMENT_REVIEW.md). Сборка и сценарии работают локально; получение реальных ударов/повреждения трупов, навигация и исполнение usercmd в QL ещё не подтверждены.

Собственный код распространяется под MIT (LICENSE). Каждый завершённый этап фиксируется в Git и CHANGELOG.md. Правила вклада — CONTRIBUTING.md, статус публикации — docs/OPEN_SOURCE.md. Удалённый GitHub-репозиторий пока не подключён; сторонние материалы сохраняют свои лицензии.

**Psyz0r_bot — тренировочный бот для Quake Live по задумке nekitz0r.** nekitz0r создаёт его вместе с помощником по разработке, чтобы получить сильного и интересного партнёра для дуэлей: отрабатывать движение, выбор оружия, контроль предметов и решения против соперника, который по ощущениям играет как человек.

**Основа — имитация человеческой игры через заранее заданные правила, состояния и сценарии.** Отдельной обучаемой ИИ-модели, нейросети или самообучения в проекте нет. Демки нужны нам как разработчикам для изучения решений игроков и настройки правил; бот не обучается на них автоматически. Целевой материал — 100 демок PsyRoZa и 20 демок nekitz0r; состав собранной подборки ещё нужно сверить с этим планом.

Бот сочетает агрессивную, среднюю и пассивную модели, постепенно подстраивается под наблюдаемый стиль соперника, выбирает давление или восстановление и меняет приоритеты предметов. При большом преимуществе может расслабиться; иногда теряет преимущество в тильте, а при доминировании соперника может психологически сдаться через безрассудную игру. Ответные реакции и согласованные реплики создают характер, а ошибки и переменный темп должны делать тренировку похожей на матч с живым игроком.

Принцип — **без WH**: решения опираются на собственное состояние, доступные зрительные и звуковые сведения, память и оценки с неопределённостью. Скрытые позиции и точные HP соперника не предназначены для логики бота. Это описание цели проекта; готовность конкретных функций и ограничения текущего прототипа указаны ниже.

Чистый C++17 проект. Откройте эту папку через Open Folder в Visual Studio с компонентами Desktop development with C++ и CMake. VS Code — редактор, MSVC — компилятор; полноценная Visual Studio тоже поддерживается через CMake.

Сборка установленными Visual Studio Build Tools из PowerShell:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\build.ps1
.\out\msvc-x64\Debug\psyz0r_sandbox.exe out\decisions.jsonl config\core.ini
python -m unittest discover -s tests -v
```

Реализовано автономное ядро трёх стилей, накопление наблюдений/урона, давление по счёту, расслабление, два независимых вида тильта, ответные цели перчатки/трупа и выбор предметной цели. Настройки читаются из config/core.ini; описание переходов и границ — docs/BEHAVIOR_IMPLEMENTATION.md. Политика чата принимает mood и ответную грубость, ограничивает частоту и циклы. Игровой исполнитель пока не подключён.

SPEC.md объединяет требования. В docs сохранены материалы и проверка исходников CONTROL_AUDIT.md. config/core.ini — действующая конфигурация; config/behavior.json — документальная копия. config/chat.json и runtime/chat.py содержат каталог и политику диалогов. assets/profile — исходный профиль для отдельной PK3-сборки.

references содержит только пять используемых референсов: quake3-source, brainworks, winqlx32, wolfcamql, uberdemotools. Источники и версии в references/manifest.json. Они не входят в нашу сборку и не являются зависимостями ядра. tools/udt содержит инструменты экспорта. QuakeLiveInterface повторно не удалось получить; актуальный архив или адрес поможет проверить управление.

Исходники внешних проектов не копируются в наше ядро. Перед включением чужого кода нужно учитывать его лицензию. Существующая папка PsyZ0r-bot и её вложенный Project_Psyz0r_bot сохранены; эта новая папка создана рядом с PsyZ0r-bot.

Одна демка:

```powershell
python tools/extract_one_demo.py "путь-к-файлу.dm_91"
```

adapter/psyz_state_probe.py — не развёрнутый read-only minqlx-пробник выбранного слота. Требует отдельного тестового сервера и явных cvar; чтение в игре ещё не проверено. Контракты game_interface.hpp не имеют игрового исполнителя. Sandbox пишет JSONL с game_command_sent=false: это журнал офлайн-решения, не подтверждение управления QL.

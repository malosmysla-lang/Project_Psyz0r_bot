# Участие в разработке

Psyz0r_bot создаётся по задумке nekitz0r как тренировочный партнёр для Quake Live. Поведение задаётся правилами и имитирует человека; отдельной обучаемой модели нет.

Каждый этап оформляем отдельным изменением в Git: задача, код/конфигурация, описание результата и проверка. После настройки GitHub публикуем коммиты и используем Issues/PR для обсуждения. Новые этапы записываем в CHANGELOG.md; рабочие ограничения — в PROJECT_STATE.md.

В PR указываем: какую ситуацию исправляем, что теперь делает бот, как проверено, какие игровые функции ещё не подтверждены. Не выдаём офлайн-сценарий за результат настоящего матча.

Проверки из корня:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/build.ps1
python -m unittest discover -s tests -v
```

Исходники собственной реализации, настройки и документация входят в Git. Демки, бинарники, сборки, чужие исходники и ресурсы остаются локально; references/manifest.json фиксирует URL и commit. Исходная лицензия стороннего кода сохраняется. До заимствования проверяем условия и совместимость, не объявляем весь внешний код своей лицензией.

Восприятие без WH обязательно. Диагностические сведения сервера не становятся входами поведения только потому, что они доступны расширению.
